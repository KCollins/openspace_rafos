# Making 3D printed DEMs with QGIS

 - [ ] Request an API key on opentopography.org
 - [ ] Download OpenTopography plugin here: https://plugins.qgis.org/plugins/OpenTopography-DEM-Downloader
 - [ ] In QGIS: Plugins>Install from Zip, install OpenTopography plugin. (This will create an icon on your top toolbar)
 - [ ] Install DEMto3D plugin: https://demto3d.com/en/descarga-e-instalacion/
